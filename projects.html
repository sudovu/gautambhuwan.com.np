VLSM BLUEPRINT

Hierarchical IPv4 / IPv6 Subnet Allocation Matrix

Continuous address plan carved from base supernet 172.16.0.0/23 (512 host addresses) and dual-stack 2001:db8:acad::/48. Designed in descending host requirement order to eliminate address fragmentation and facilitate instant WAN route summarization.
