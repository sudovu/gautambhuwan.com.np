CASE STUDY // REAL-WORLD AUDIT & REDESIGN ZERO-TRUST HIERARCHY

Enterprise Network Transformation: Flat vs. Segmented Architecture

A comprehensive engineering redesign for a multi-building enterprise campus. Comparing the vulnerabilities of an unmanaged flat network topology against a high-security, 3-tier zero-trust architecture separating Wireless, LAN Network Points, CCTV Surveillance, and IP Telephony (VoIP).

WIRELESS • DATA LAN • CCTV • IP TELEPHONY
LEGACY UNMANAGED

Flat Layer 2 Unsegmented Topology

HIGH RISK: ZERO ISOLATION • SERIAL 100M CHOKE POINTS

1. Shared Broadcast & Collision Domain

All endpoints across all buildings shared a single flat subnet. Every ARP request, network broadcast, and device discovery flooded all switchports, creating network-wide packet storms.

2. Lateral Threat Spread & Sniffing

Because there was zero VLAN segmentation, any visitor connected to an access point or any infected workstation could directly scan and sniff internal administrative traffic and surveillance streams using simple packet sniffers.

3. 100M Daisy-Chained PoE Bottleneck

PoE switches powering CCTV cameras were linked together via a serial 100 Mbps uplink. During simultaneous multi-camera high-definition recording, this link became a major choke point, causing severe dropped video frames.

4. CCTV Surveillance Exposed to the Internet

CCTV cameras and the NVR shared default internet access with employee computers. Without an isolated firewall zone, camera firmware was exposed to potential remote exploitation or unauthorized viewing.

5. Zero Voice Prioritization (QoS)

Staff trying to run softphones or IP telephone calls suffered from severe voice distortion and call drops because voice packets competed with heavy file downloads without any Quality of Service tagging.

6. Cascading Switch Failure Points

Cascading unmanaged desktop switches across multiple buildings created daisy-chained loops and single points of failure. If an intermediary switch lost power, entire buildings lost connection.

ENGINEERED RESTRUCTURE // ZERO-TRUST

Hierarchical 3-Tier Segmented Architecture

OPTIMIZED: FULL 802.1Q ISOLATION • VOICE QOS • CCTV ENCLAVE

TABLE 1.0 Logical Network Segmentation Matrix (802.1Q VLANs & Access Control)

VLAN ID & Name Subnet (CIDR) Usable Hosts Gateway Security Posture Access Control List (ACL) Rules
VLAN 10: MGMT 10.60.10.0/24 254 10.60.10.1 High Security Permit IT Subnet only. Deny all inter-VLAN. Deny Internet inbound.
VLAN 20: STAFF 10.60.20.0/23 510 10.60.20.1 Medium Security Permit Internet. Permit local shared printers. Deny access to VLAN 60 (CCTV).
VLAN 30: STAFF-WIFI 10.60.30.0/23 510 10.60.30.1 Medium Security Bridged to Staff Data. Permit Internet. Enforce 802.1X Enterprise authentication.
VLAN 40: GUEST 10.60.40.0/22 1022 10.60.40.1 Isolated (Zero Trust) Permit Internet ONLY. Enforce Layer 2 Client Isolation. Deny all internal enterprise subnets.
VLAN 50: VOICE 10.60.50.0/24 254 10.60.50.1 High Priority (QoS) Permit PBX server registration. Enforce strict DSCP Expedited Forwarding (EF). Deny general data.
VLAN 60: CCTV 10.60.60.0/24 254 10.60.60.1 Maximum Security Permit NVR communication only. Deny Internet access completely to eliminate hacking risks.

ADVANTAGES Measurable Technical Advantages Achieved After Separation

1. Zero-Trust Security & Malware Containment

Broadcast domains are strictly confined to individual subnets. If an infected device enters Guest Wi-Fi, lateral malware spread across the enterprise is stopped dead at switch hardware ASICs.

2. CCTV Total Isolation (0% Internet Exposure)

By enforcing an explicit deny internet firewall policy on VLAN 60, IP cameras and the NVR are completely isolated from the outside world. Cameras cannot leak video or be recruited into botnets.

3. Deterministic Voice QoS (Zero Dropped Calls)

Voice traffic on VLAN 50 receives DSCP Expedited Forwarding (EF) with strict priority queueing. Phone conversations between all desk extensions and reception remain crystal-clear even during peak link utilization.

4. Elimination of Daisy-Chain Choke Points

Replaced serial 100M daisy-chained PoE switches with dedicated Gigabit star downlinks from the Managed Core Switch. Eliminates bottlenecks and provides full line-rate throughput for all cameras.

5. High-Speed L2-Isolated Guest Wi-Fi

Guest users on VLAN 40 receive isolated internet connectivity with Layer 2 Client Isolation enabled. Visitors cannot browse local network shares or communicate with other connected devices.

6. Structured Network Points Standard

Dedicated Cat6 terminations for PC data and IP telephony provide organized cable distribution with easy maintenance and clean port auditing.
